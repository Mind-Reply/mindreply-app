# a11-ios-zero-interruption

## Purpose
Guarantee that Angel's iOS experience is never interrupted by apps, notifications, background activity, or system noise. The opposite of interruption: calm, continuous, high-signal presence that supports focus and achievement.

## Absolute rule
No app, connector, agent, or surface may interrupt Angel on iOS at any point. Interruptions are forbidden. The system must actively reduce and eliminate them.

## What counts as an interruption (forbidden)
- Push notifications, banners, sounds, or badges from any app
- Background App Refresh pulling data silently
- Time-sensitive or critical alerts from non-essential apps
- Lock-screen previews or scheduled summaries that break attention
- App switcher or home-screen noise
- Any agent or automation firing a notification while Angel is in flow

## What is allowed (positive outcomes only)
- Direct human communication when required: calls, FaceTime, Messages from approved contacts
- Physical meetings, deliveries, signings, or in-person coordination
- Owner-initiated actions that produce measurable achievement
- Emergency or safety alerts only when truly life-critical

## Operating posture
- Enterprise-grade, brave, prepared, high-end, passionate, energetic, awake
- Long-term operations over short-term noise
- Multi-goal execution without distraction
- Jump on challenges; do what others cannot
- No manuals, no terminal codes, no copy-paste, no amateur work
- Investigate and fulfill directly through connected services (MCP-driven)
- Only escalate to physical human action when no digital path exists and the outcome is positive

## iOS configuration (agent-enforced where possible)
1. Enable a custom Focus mode named "A11 Zero Interruption"
   - Allow notifications only from: Phone, FaceTime, Messages (approved contacts), Calendar (owner events)
   - Silence all other apps, social, ads, news, shopping
   - Turn off Time Sensitive for everything except true emergencies
   - Hide lock-screen previews for non-allowed apps
   - Schedule it always-on or by time/location as needed
2. Background App Refresh: OFF globally, or ON only for Calendar/Maps when travel requires it
3. Low Power Mode: use only when battery demands; it is not a substitute for Focus
4. Notification Summary: enable for any residual low-priority items
5. Any connected app (Slack, Gmail, Notion, ads, etc.) must respect Focus and never bypass it

## Agent behavior
- Before any action that could surface on iOS, check Focus state and owner presence
- Prefer silent, durable state updates over notifications
- Route all alerts through the canonical record; never fire raw pushes
- If an interruption risk is detected, convert it into a non-interrupting Owner Action Packet only when a positive outcome requires human presence
- Continuously audit connected services for notification settings that violate this rule

## Verification
- iOS Focus active and correctly configured
- No unauthorized notifications delivered in the last 24h
- Background refresh disabled for non-essential apps
- All agent outputs respect the zero-interruption contract

## Anti-patterns
- Sending a notification "just in case"
- Allowing any connector to bypass Focus
- Treating activity volume as value
- Manual copy-paste instructions for the owner
- Any amateur or terminal-based workaround
