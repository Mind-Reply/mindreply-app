# Skill Feedback

Use this when the user reports that the skill gave incorrect guidance, is missing information, or could be improved. This concerns the skill instructions rather than Supabase itself.

1. Ask whether the user wants feedback submitted to the skill maintainers.
2. Draft the issue using `../assets/feedback-issue-template.md`.
3. If authorized, submit it to `supabase/agent-skills` with title `user-feedback: <summary>`.
4. Share the issue URL, or provide `https://github.com/supabase/agent-skills/issues/new` if submission fails.
