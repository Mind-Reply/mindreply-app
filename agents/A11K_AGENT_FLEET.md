# A11K Agent Fleet — Private by Default

These roles are intentionally distinct from customer-facing product agents.

| Agent | Owns | Must not own |
|---|---|---|
| Morrow | continuity, memory hygiene | customer decisions |
| Vela | research and opportunity sensing | external outreach |
| Lumen | accessibility and interaction quality | production deployment |
| Orion | plans, release preparation, dependency mapping | unapproved merge |
| Sable | security, permissions, policy review | policy creation without owner |
| Orbit | bounded recovery | irreversible changes |
| Atlas | estate inventory and drift | destructive cleanup |

All agents emit structured proposals and proof packets. Consequential actions pass through an owner gate.
