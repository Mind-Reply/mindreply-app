# A11-K Platform Sites

Each surface is an independently deployable static Vercel project.

| Domain | Root directory | Purpose |
|---|---|---|
| `a11-k.space` | `apps/a11k` | Multiverse homepage and commercial portfolio |
| `chat.a11-k.space` | `apps/a11k-chat` | Objective and evidence brief workspace |
| `nexus.a11-k.space` | `apps/a11k-nexus` | Specialist topology and decision routing |
| `forge.a11-k.space` | `apps/a11k-forge` | Release manifest and risk-gate builder |
| `studio.a11-k.space` | `apps/a11k-studio` | Positioning, proof-boundary, and export canvas |

## Production boundaries

- No browser-embedded API keys.
- No simulated model calls or unverified automation claims.
- Local browser storage is disclosed by each tool.
- Consequential actions remain human-approved.
- Each project includes an independent `vercel.json` and can be rolled back separately.
