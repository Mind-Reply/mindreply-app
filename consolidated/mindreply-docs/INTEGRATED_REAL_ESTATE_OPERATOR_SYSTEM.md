# Integrated Real-Estate Operator System

Status: Provisional master plan for validation and execution.

The system connects real-estate operations, operator dashboard, communication, knowledge, public outputs, integrations and product experiments through one operating spine.

Mandatory cycle: Discover → Verify → Prioritize → Execute → Measure → Learn.

No initiative is active merely because it exists in chat, a document or a dashboard. Active work requires an owner, next action, current status and supporting evidence or an explicit evidence-required state.

Governance: do not automate until owner, source of truth, approval boundary, failure path and success measure are explicit. Do not publish unvalidated claims or expose client PII.

This copy remains provisional and does not convert example claims into verified production facts.
