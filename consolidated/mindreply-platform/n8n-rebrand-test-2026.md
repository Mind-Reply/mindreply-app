# n8n Rebrand Test & Activation Charter — 2026-09

## Operating role
A11pro treats the proposed n8n rebrand as a controlled product/brand experiment. This does not claim ownership of, endorsement by, or an official rebrand of n8n.

## Rebrand direction under test
Private product layer: Execution Fabric.

Supporting language:
- operator-controlled workflows
- decision-to-execution infrastructure
- governed orchestration
- reversible execution
- evidence-backed operations
- commercial execution layer

## Canonical workflow
SIGNAL → DIAGNOSIS → PROPOSED ACTION → OWNER APPROVAL → EXECUTION → VERIFICATION → LEDGER

## Governance
Separate test and production, isolate credentials, use role-based access, audit trail, workflow versioning, explicit approval boundaries, rollback/recovery and synthetic test data.

## Verification
Happy-path, failure-path, duplicate-event, timeout/retry, permission, data-integrity, rollback and evidence-capture tests.

## Promotion
Promotion is evidence-based: critical tests pass, no unresolved control blocker, no unsupported public claims, protected production boundary, owner approval and rollback path.
