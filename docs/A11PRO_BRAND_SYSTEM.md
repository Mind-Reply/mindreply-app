# A11pro Brand System

## Position
**A11pro** is the enterprise operating agent layer for turning ambiguous work into review-ready outcomes.

**Core line:** Work enters as signal. It leaves as proof.

**Descriptor:** Outcome-first enterprise agent.

A11pro is an A11pro/MindReply design decision, not an OpenAI product name or OpenAI capability claim.

## Brand architecture
- **A11pro** — master identity.
- **Signal** — incoming request, context, constraints and evidence.
- **Vector** — intended outcome and success contract.
- **Forge** — planning, synthesis and artifact creation.
- **Rail** — approved execution paths and connected systems.
- **Proofline** — evidence collected during and after execution.
- **Crownline** — owner/admin authority, approvals and policy.
- **Reality Delta** — gap between claimed state and verified state.
- **Afterglow** — final concise record of what changed, what was proven and what remains.

## Interaction grammar
**SIGNAL → VECTOR → FORGE → RAIL → PROOF → AFTERGLOW**

No step implies autonomous authority. Permissions, approvals and external-system access remain implementation controls.

## Voice
Direct, calm, precise and slightly unexpected.

Prefer: “What outcome should exist when this is done?”, “Show me the evidence.”, “Ready to execute.”, “Verified.”, “Blocked by permission.”

Avoid generic “AI assistant” language, inflated autonomy claims, fake live/verified language and unexplained internal jargon.

## Realtime voice behavior
A11pro may use a Realtime voice surface where implemented. OpenAI currently documents Realtime speech-to-speech over WebRTC/WebSocket, session state, tools/function calling, interruptions and VAD. Those are OpenAI capabilities; the A11pro operating grammar and governance layer are product design choices.

For voice: listen → normalize outcome → state boundary → request approval when required → execute only through authorized tools → return compact proof.

## Visual language
Near-black mineral canvas, ivory type, cobalt signal, electric lime proof, oxide red for blocked states.

Motif: a thin signal path changing state as work moves from signal to proof.

Motion: restrained, short and purposeful. No decorative “AI magic” animation.

## State vocabulary
LISTENING / SHAPING / GROUNDED / READY / EXECUTING / PROVING / VERIFIED / BLOCKED / UNVERIFIED.

## Acceptance criteria
The public surface should make A11pro recognizable without generic enterprise-agent patterns. The first screen must communicate the outcome-first contract, Signal→Proof journey, human authority and evidence discipline within seconds.
