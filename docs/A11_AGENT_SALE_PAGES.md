# A11 Agent & Operator Sale Pages — Spotless Contract

**Status:** ACTIVE  
**Owner:** CEO A.K.  
**Purpose:** Define what may be sold publicly from the A11 / Mind-Reply estate without violating the Reality Index or Trust surface.

---

## Non-negotiable sale rules

1. Every public offer must have one sentence value, one proof strip, one real CTA.  
2. Never claim autonomous control of a customer’s machine, cloud project, or money.  
3. Never promise “phone-anywhere full power” without stating the always-on gateway + approval gates.  
4. Price and delivery path must be real (Stripe, invoice, or clear human handoff).  
5. Language stays soft, precise, and checkable. No “100%”, “risk-free”, or “fully autonomous enterprise AI”.

---

## Approved product frames (current)

### 1. Profit Audit — €3,000 (already live)
- **One sentence:** A seven-day technical-commercial audit that clarifies release controls, automation reliability, and operational margin.  
- **Proof strip:** Live Stripe path + documented scope in README and Master Record.  
- **CTA:** Existing book link on mind-reply.com / monorepo README.  
- **Delivery:** Human-led, evidence package, no secrets requested in chat.

### 2. A11 Private Operator Pack (documentation + hierarchy)
- **One sentence:** The owner-governed agent hierarchy, operating constitution, 43-target machine, and Trust surface that A11 actually runs on.  
- **What is delivered:** The public docs in this monorepo (`A11_MASTER_RECORD`, `A11_PRIVATE_AGENT_HIERARCHY`, `43_TARGETS`, Public Pages Contract) plus a configuration workshop.  
- **What is not delivered:** Live access to the private CEO agent mesh, cloud runtime, or any credential.  
- **CTA:** Briefing request (mailto or approved form) → scoped engagement.

### 3. Specialist configuration engagement
- **One sentence:** Stand-up of one named specialist (implementation, security-plan, research, or fulfillment) under the owner’s governance rules.  
- **Boundary:** Specialist still reports to a human owner; no independent spending or production deploy authority.  
- **CTA:** Same briefing path; statement of work before any work starts.

### 4. Future — Mobile private console (PWA)
- **Positioning only until live:** “A private, approval-gated command surface reachable from your phone.”  
- **Requirements before sale:** Always-on private gateway, passkey/MFA, per-action approval, audit log, emergency stop.  
- **Until those exist:** Do not sell mobile access as a product.

- “Configuration and operating model for evidence-led specialist agents.”

## Language that is forbidden

- “Buy an unrestricted A11 agent that controls your PC from your phone.”  
- “Fully autonomous robotic / enterprise agent ready to deploy.”  
- “We run Gemini Enterprise Agent Runtime for you with no further setup.” (unless a verified customer project and contract exist)
