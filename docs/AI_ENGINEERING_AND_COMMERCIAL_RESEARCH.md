# MindReply web-replycontrol

This app contains the public-facing web surface for the MindReply product and includes a Stripe checkout scaffold for the existing Website Completion Package.

## Current status

- Public web surface is active in the repository.
- Stripe integration is intentionally scaffolded and test-mode only.
- Real payment and webhook activation requires provider-side configuration and owner authorization.

## Required environment variables

- `STRIPE_SECRET_KEY`
- `STRIPE_WEBHOOK_SECRET`
- `STRIPE_PRICE_ID_WEBSITE_COMPLETION`
- `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`
- `NEXT_PUBLIC_APP_URL`

Never commit real secrets to Git.

## Local flow

1. Create a Stripe test-mode product/price.
2. Add the values to `.env.local`.
3. Start the app.
4. Visit `/pricing` and begin checkout.
5. Verify webhook events using the Stripe CLI or a secure test endpoint.

The checkout process is test-mode only until live provider evidence exists.
