# Archived Documentation

This folder contains historical deployment, launch, and planning documents that are **no longer authoritative** and **must not be used as current deployment instructions**.

These files are preserved for reference only. All current operational guidance is in:

- `../../DEPLOYMENT_GUIDE.md` — Current deployment procedures
- `../../README.md` — Current project status
- `../../SECURITY.md` — Current security baseline

## Why these are archived

Historical documents often contain:
- Outdated hostnames / URLs
- Unverified claims about deployment status
- Unvalidated revenue/performance targets
- Superseded CI/CD configurations
- Stale credential / environment variable examples

**Do not copy values from these files into production.**
