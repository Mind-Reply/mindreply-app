# Command Atelier

The canonical MindReply repository now contains the v0 Command Atelier surface at `/command-atelier`.

Implemented as a working Next.js/React interface, not a static mockup:
- MindReply / Institution: evidence ledger and honest-state estate index.
- A11-K / Atlas: four-territory topology with keyboard navigation.
- Briefing Chamber: local-first structured drafting, save/history boundary, copy and Markdown export.
- Decision Observatory: accountable routing tree with explicit queued-vs-running distinction.
- Release Foundry: deterministic six-gate local validation and JSON/Markdown manifest export; never claims deployment.
- Signal Press: proof/boundary composition canvas and claim check; no publishing action.

Guardrails:
- No fake telemetry, fake agent execution, fake metrics, or fake deployment state.
- No secrets are requested or embedded.
- Owner approval remains explicit and false until a real approval action exists.
- Local persistence is used only for local drafting.
- Reduced-motion and high-contrast focus states are included.
