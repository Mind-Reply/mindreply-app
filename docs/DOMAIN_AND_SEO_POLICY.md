# Domain and SEO Policy

This repository should support a clean domain strategy, not a pile of interchangeable subdomains.

## Rules

- One primary purpose per domain.
- Use descriptive names for public sites and owner surfaces.
- Keep private tools on separate, non-indexed surfaces.
- Prefer stable routes over clever naming.
- Eliminate dead links before promotion.
- Never claim a page or product is live without a verified response path.

## Selection checklist

Before using a domain or subdomain, check:

1. Does it describe the actual function?
2. Is it short enough to remember?
3. Can it be indexed, secured, and monitored clearly?
4. Does it avoid overlap with a private owner tool?
5. Can it survive future expansion without renaming everything?

## SEO guidance

- Put one strong phrase in the title tag.
- Use one clear H1.
- Keep meta descriptions human and specific.
- Avoid duplicated landing pages with tiny wording changes.
- Point canonical URLs at the primary version of each page.

## Operational rule

If a page is not meant to be public, it should not be promoted as if it were. Private surfaces stay private; public surfaces stay clean and indexable.
