# Human Signal Lexicon

**Purpose:** A distinctive vocabulary for MindReply / A11-K surfaces.  
**Rule:** Prefer language that sounds like people who ship under pressure—not like a model describing itself.

## Banned (generic AI register)

Avoid or heavily restrict:
- AI-powered · intelligent · seamless · revolutionary · unlock · harness · leverage (as verb for tools)
- agents are working · autonomous swarm · next-gen · cutting-edge · transformative
- magic · just works · zero effort · set and forget

## Preferred field language

| Concept | Prefer | Avoid |
|---------|--------|-------|
| System | answerable system, operating circuit | AI platform |
| Work unit | knot, clearing, brief | ticket, prompt |
| Decision | named hand, stop rule, clearance | auto-approve |
| Quality | gate, barrier, rewrite once | score dashboard |
| Memory | proof trail, envelope, receipt | chat history |
| Authority | human command, owner-led | autonomous |
| Release | reversible slice, way back | ship fast |
| Intent | what must become true | user prompt |
| Boundary | the line we will not cross | policy |
| Outcome | one accountable next move | insights |

## Signature phrases (use sparingly, own them)

- Responsibility follows evidence.
- People keep the last word.
- Machines wait; people decide.
- Proof before permission.
- A plan is not a dispatch.
- A manifest is not approval.
- Nothing leaves this browser until you say so.
- Start with what already exists.

## Layer names (keep; never dilute)

- **Aurelia** — intent becomes policy someone can read tomorrow
- **Lumenforge** — bad output meets a wall, not a metric
- **Veridex** — every consequential step leaves a receipt

## Tone

Calm. Specific. Slightly industrial. Never breathless.  
Write as if the reader has already been burned by tools that promised too much.
