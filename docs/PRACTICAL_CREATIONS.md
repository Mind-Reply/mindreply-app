# Practical creation capabilities (what ships reliably)

**Owner use this as the capability contract** — not marketing.

## Highest leverage in practice

| Rank | Capability | What you get | Tool path |
|------|------------|--------------|-----------|
| 1 | **Canonical identity + ops docs** | Kill name chaos; agents stop working wrong repos | GitHub push → registry, brand, competitive |
| 2 | **Code + design tokens on live surfaces** | Real CSS/HTML/TS updates on Tier-0 sites | GitHub create/update file |
| 3 | **High-end brand assets** | Logos, boards, product marks | Canva generate + save design |
| 4 | **Competitive structure research** | Leader matrices → product decisions | Web search + docs |
| 5 | **Maintenance automation config** | Dependabot groups, CI policy, freeze names | GitHub workflows / yml |
| 6 | **Scheduled Grok automations** | Daily health / opportunity loops | Automations connector (quota dependent) |
| 7 | **Deploy / project link** | Vercel git projects, previews | Vercel connector |
| 8 | **Visual decks** | Gamma (when credits available) | Gamma generate |

## What “reconstruct / rename / create” means here

1. **Reconstruct** = rewrite tokens, identity, competitive rules so the *system* is coherent  
2. **Rename** = freeze production names; ARCHIVE aliases (GH rename of canonical is rare; Vercel display names preferred)  
3. **Create** = only missing Tier-0 artifacts (docs, brand, maintenance packs, logo masters) — not 70th clone repo  

## Competitive practice (2026)

- CX leaders: Intercom/Fin, Zendesk AI, Front — we counter with **continuity + evidence + predictable cost story**  
- Agent leaders: LangGraph-class state/HITL — we counter with **registry-bound agents + fail-closed policy**  

See `COMPETITIVE_STRUCTURE.md`.

## Limits to plan around

- Automations: **task usage limit** can block new daily jobs until quota resets  
- Gamma: credit limits  
- Vercel Hobby: project cap — pause aliases, don’t spawn new noise  
- Never paste secret *values* into chat or docs  

## Default execution order for owner asks

```
VERIFY registry → PICK Tier-0 surface → APPLY brand/competitive →
MAINTAIN (dependabot/CI) → AUTOMATE if quota → DEPLOY only when ordered
```
