# MindReply Vocabulary System

## Purpose

Create a recognizable language without sacrificing comprehension, search relevance, or technical accuracy. Distinctive terms are labels, not substitutes for evidence.

## Core lexicon

| Branded term | Plain meaning | Use for | Do not use for |
|---|---|---|---|
| **Proofline** | Evidence path from code change to verified outcome | CI, release, audit, fulfillment evidence | Generic project management |
| **Crownline** | Owner-governed command and approval layer | permissions, approvals, policy, production gates | Unrestricted automation |
| **ProofGate** | Blocking validation checkpoint | tests, security checks, deployment approval | Non-blocking reports |
| **Continuity Ledger** | Durable context and decision record | memory, decisions, provenance, handoffs | raw secrets or private credentials |
| **ReplyRail** | Approved communication and delivery workflow | Twilio, WhatsApp, notifications, fulfillment | unsolicited outreach |
| **Operator Guild** | Bounded specialist automation set | role-based agents with explicit permissions | autonomous production authority |
| **Reality Delta** | Difference between claim and verified state | audits, monitoring, stale documentation | marketing exaggeration |
| **Patternwright** | Visual-system workbench | components, design tokens, interface prototypes | a generic image generator |
| **Venture Foundry** | Concept-to-deployment workbench | offers, brands, pipelines, launch evidence | automatic company creation |
| **Signalcraft Audit** | Evidence-led technical-commercial review | GitHub, Python, CI/CD, automation margin | security certification |

## SEO rule

Pair one distinctive term with one clear search phrase:

- “Proofline — GitHub release engineering and CI/CD security”
- “ReplyRail — Twilio WhatsApp workflow automation”
- “Signalcraft Audit — GitHub repository and Python automation audit”
- “Patternwright — design-system and component engineering workbench”

Never publish a page made only of invented words.

## Writing rule

Prefer concrete verbs: verify, route, approve, reconcile, release, rollback, measure, deliver.

Avoid overused filler: revolutionary, cutting-edge, intelligent ecosystem, seamless, next-generation, autonomous, magical, powered by AI.

Use “AI” only when it identifies an actual model-backed function. Otherwise name the function.

## Code rule

Do not rename environment variables, database tables, API routes, package names, or deployment identifiers for branding alone. Change technical identifiers only through a tested migration.
