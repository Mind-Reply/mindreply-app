# A11P-007 — Frontier Research Signal Record

Status: RESEARCHED / OWNER-GATED
Date: 2026-09-25
Scope: bounded inputs for A11pro architecture; no production adoption implied.

## Signal 1 — Managed agent harnesses now expose durable orchestration primitives
OpenAI's Agents API is in public beta and provides a managed Codex harness with session persistence, context compaction, tool search, programmatic tool calling, and subagent delegation. OpenAI's architecture documentation explicitly separates the harness, execution environment, and application server.

Source: https://openai.com/index/introducing-the-agents-api/
Source: https://developers.openai.com/api/docs/guides/agents-api/architecture

A11pro response: KEEP AS AN ARCHITECTURAL REFERENCE, not as a reason to surrender owner control. Preserve a distinct application-side authorization/evidence layer. Subtasks may be delegated, but promotion remains owner-gated and execution destinations remain explicit.

## Signal 2 — Realtime voice now supports stronger reasoning and tool use
OpenAI documents GPT-Realtime-2 as a realtime reasoning model with function calling and tool use, and the Realtime guide recommends ephemeral client secrets for browser sessions rather than exposing long-lived credentials.

Source: https://developers.openai.com/api/docs/models/gpt-realtime-2
Source: https://developers.openai.com/api/docs/guides/realtime

A11pro response: KEEP the capability as an optional command-surface input. Do not bind voice directly to irreversible operations. Route voice intents through the same owner authorization, staged-action, evidence, and release gates as typed commands.

## Signal 3 — Cloudflare Containers make edge Worker + container execution a current supported runtime pattern
Cloudflare's current Containers documentation describes Worker-controlled container instances and production deployment through Wrangler. The deployment documentation warns that image build/push/rollout steps are not transactional and that a Worker can become live before a later container rollout error.

Source: https://developers.cloudflare.com/containers/
Source: https://developers.cloudflare.com/containers/guides/deploy/

A11pro response: KEEP the runtime pattern, but explicitly separate deployment completion from destination verification. A successful deployment command is not sufficient evidence of application health. ResellerPro remains the control-plane authority; Cloudflare remains the runtime target only after release authorization.
