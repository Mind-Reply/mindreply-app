# v0 Generation Prompts

Use each prompt in a separate v0 chat. Attach only public-safe source and this design brief. Never attach environment files, tokens, credentials, private repositories, or owner-only control logic.

## Global system context

You are the visual-command team for Command Atelier, an enterprise AI operations estate. Produce a working Next.js 16 / React 19 interface—not a static mockup. Use semantic HTML, keyboard operation, WCAG-aware contrast, reduced-motion support, and responsive compositions at 1440px and 390px.

Avoid generic AI aesthetics: no purple-blue gradient fog, floating glass cards, glowing orbs, random particles, decorative dashboards, stock robots, or repeated SaaS sections. Use asymmetric editorial composition, severe typography, spatial diagrams, meaningful operational rails, evidence drawers, and restrained state-driven motion.

Use this material system: obsidian `#070809`, mineral paper `#ECEAE4`, cobalt `#4169FF`, volt `#C8FF3D`, oxide `#FF5A44`, graphite rules. Each border must communicate containment, sequence, or relationship.

Do not fake API/model output. Controls that lack a backend must be explicitly local and fully functional in the browser. Never include secrets or request credentials.

Return: complete code, component map, interaction inventory, accessibility notes, desktop/mobile behavior, and preview URL.

---

## 01 — MindReply / The Institution

Create an enterprise corporate presence for MindReply that feels like an operating institution, not an AI startup.

Opening composition: an editorial operating thesis that reads “Intelligence must answer to the work.” Pair it with a live-looking but honest Evidence Ledger showing three principles: authority is named, proof is visible, release is reversible. This is a visual status instrument—not fake telemetry.

Build four passages instead of standard sections:
1. Operating thesis and evidence ledger.
2. Estate index: Crownwork, A11-K, Repository Clarity—shown as distinct operating mandates.
3. Proof-bearing method: Knot → Circuit → Proof trail → Widening.
4. Quiet commercial entry with the existing repository-audit CTA.

Make the mobile composition feel like a pocket briefing book. Keep one dominant action. No testimonial logos, fake metrics, or unsupported production claims.

---

## 02 — A11-K / The Atlas

Create a spatial command atlas for the A11-K estate.

The main viewport is a navigable topology with four territories: Chat, Nexus, Forge, Studio. Each territory has unique geometry and an operational purpose. Selecting one should redraw the topology, reveal its boundary and evidence requirements, and expose a clear route to that platform.

Include an Estate State rail that accurately distinguishes: public surface, connection required, preview required, and owner-approved. Do not represent queued agent slots as running.

The mobile version becomes a vertical expedition map, not a grid of cards. Navigation must work without pointer hover.

---

## 03 — Chat / The Briefing Chamber

Create a local-first objective briefing chamber.

The interface has four physical planes:
- Objective: what must become true.
- Verified context: facts, constraints, dependencies.
- Proof standard: what accepted progress looks like.
- Authority line: what requires human approval.

Interactions: compose a structured brief, save to local storage, view local history, copy, export Markdown, delete local data, and inspect the connection boundary. No model call and no simulated AI response.

Use the metaphor of a drafting table with evidence margins and an authority seal. The mobile version should become a focused step-by-step briefing sequence with a persistent local-only indicator.

---

## 04 — Nexus / The Decision Observatory

Create an enterprise multi-agent topology and decision-routing observatory.

Represent the real hierarchy:
Owner gate → Orchestrator → Platform captain → Specialist frontiers → Accessibility/Red-team/Evidence gates → Release lead.

Support states: queued, claimed, in progress, blocked, needs review, evidence accepted, owner approved. Clearly state that the 150 fleet slots are queued definitions unless a real runner has claimed them.

Interactions: select a platform, inspect its team tree, trace a proposed route, reveal gates, compare state, and export a routing plan. Use spatial linework and meaningful transitions—not decorative node bubbles.

At 390px, transform the topology into an expandable command tree with preserved hierarchy and status.

---

## 05 — Forge / The Release Foundry

Create a release-control foundry where work moves through a visible passage:
Evidence → Security → Ownership → Observability → Rollback → Human approval.

Interactions: define product/repository, outcome, constraints, release type, owner, acceptance tests, stop rules, rollback path, and observability signals. Generate a local manifest, copy Markdown, export JSON, and revisit a locally saved draft.

Each incomplete gate must show exactly what is missing. No control can deploy, merge, alter billing, or claim certification. The final state is “Ready for owner review,” never “Deployed.”

Use industrial sequencing, stamped evidence, and spatial progression without cliché gears or factory illustration.

---

## 06 — Studio / The Signal Press

Create an enterprise visual and narrative production desk.

The workspace includes:
- Positioning line.
- Verified proof library.
- Explicit boundary ledger.
- Composition canvas.
- Desktop/mobile preview.
- Markdown and standalone-HTML export.

Allow users to arrange proof and boundary blocks into an editorial release artifact. Flag any claim without supporting proof. The tool does not publish.

Visual language: an intelligent signal press—editorial grids, crop marks, proof annotations, composition rulers, and a calm preview stage. Avoid a Canva clone or generic form builder.

## Review instruction for every v0 result

Reject and regenerate if the result contains:
- generic centered hero + three cards;
- purple/blue gradient fog;
- dead buttons;
- desktop-only interaction;
- fake analytics or live-agent states;
- inaccessible contrast/focus;
- repeated visual structure across all six platforms;
- secrets, private URLs, or unverified claims.
